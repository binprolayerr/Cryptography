# picoCTF Easy Writeups
Các bài giải cho các thử thách **Cryptography - Easy** trên **picoCTF**.
Mỗi thư mục tương ứng với một challenge cụ thể và chứa một file `WRITEUP.md` mô tả đề bài, cách giải, công cụ sử dụng và flag cuối cùng.
## Cấu trúc thư mục
* `13/`
* `EVEN RSA CAN BE BROKEN???/`
* `Mod 26/`
* `The Numbers/`
* `hashcrack/`
* `interendec/`
## Tools gợi ý
* Tools: `CyberChef`, `RSA Cipher`, `Crackstation`.
# Ghi chú
Mỗi thư mục chứa file WRITEUP.md sẽ mô tả đề bài, ý tưởng giải và công cụ để decode, kết quả.
